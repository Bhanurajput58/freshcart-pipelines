# FreshCart Pipelines

Data Engineering (CS-8037) Assignment.

## Project Overview

This project demonstrates:

1. Git and CI/CD
2. FreshCart ELT pipeline using Snowflake
3. Machine Learning pipeline using Mage
4. Food-order event streaming using RabbitMQ

## Technologies

- Python
- Git and GitHub
- Snowflake
- Mage
- RabbitMQ
- Pytest

## CI Testing

GitHub Actions CI workflow is configured
to automatically run pytest on every push
to the main branch.
